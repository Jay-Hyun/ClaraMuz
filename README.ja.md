# ClaraMuz

### ClaudeとChatGPTを1つのチームとして働かせるプラグイン

![ClaraMuz 概要](docs/img/ja/hero.svg)

## ひとことで言うと

**仕事を2つのAIで分担し、途中の作業はメモで引き継ぎます。** ClaudeアプリでもChatGPTアプリでも、1回インストールするだけです。

## こんなときに使います

| 場面 | ClaraMuzがすること |
|---|---|
| 「作るのはChatGPT、レビューはClaudeにしたい…」 | 作業を分けて2つのAIに任せ、結果は**自分でファイルを開いて確認**してから報告します |
| 「Claudeの利用上限に達した！」 | ここまでの作業と残りを**引き継ぎメモ**にまとめます。続きはChatGPTで行えます ![引き継ぎ](docs/img/ja/handoff.svg) |
| 「さっき決めたルールをまた説明したくない」 | 2つのAIが読む**共有メモ**に書いておけば、両方が読みます |

## しくみ

- インストールするのは**説明書(スキル)2つ**です。プログラムではないので軽く、Node.jsなどの追加ツールも不要です。
- 共有メモは、お使いのPC上の普通のファイルです(`~/.clara-muz/memory/`)。テキストエディタで開いて編集できます。
- 作業を分けるとき、リーダーのAIは相手のAIのコマンド(`codex` または `claude`)を呼び出します。無ければ**AIが先に「インストールしてよいですか？」と確認します。**

| スキル | こう話しかけてください |
|---|---|
| `clara-muz-team` | 「2つで一緒にやって」「もう1つのAIにもレビューさせて」「実装はGPT、レビューはClaude」 |
| `ai-memory` | 「メモして」「共有メモを見せて」「引き継ぎ文書を作って」 |

## インストール

![アプリの準備](docs/img/ja/step1.svg)

まず**Claudeデスクトップアプリ**または**ChatGPTデスクトップアプリ**(使う方)をインストールしてログインします。両方あれば、2つのAIで作業を分担できます。

| ガイド | 対象 |
|---|---|
| **[GUIインストールガイド](docs/INSTALL-GUI.ja.md)** | ターミナルなしで、アプリ内のクリックだけでインストールしたい方(**おすすめ**) |
| [CLIインストールガイド](docs/INSTALL-CLI.ja.md) | ターミナルを使う開発者 |

### ひと目で分かる: アプリでインストール

**Claudeアプリ:** **Customize → Plugins → Add → Add marketplace** を開き、`Jay-Hyun/ClaraMuz` を入力して `clara-muz` を追加します。

![Claudeにインストール](docs/img/ja/install-claude.svg)

**ChatGPTアプリ:** **Plugins → プラグインのマーケットプレイスを追加** を開き、**ソース**に `Jay-Hyun/ClaraMuz` を入力して(他の欄は空欄のまま)追加し、`clara-muz` をインストールします。会社の管理者は **Admin → Plugins → Import marketplace** で全員に配布できます。

![ChatGPTにインストール](docs/img/ja/install-chatgpt.svg)

> 上の画像は公式ドキュメントと実際のアプリ画面を参考にした**イメージ図**です。メニュー名はアプリのバージョンで異なる場合があります。詳細とトラブル対処は[GUIインストールガイド](docs/INSTALL-GUI.ja.md)をご覧ください。

### 片方のアプリだけでも使えますか？

はい。ただし2つのAIが**一緒に作業するには、相手のAIのコマンドを実行できるモード**(ClaudeのCode、ChatGPTのCodex)で使う必要があります。通常のチャット画面ではファイル保存やコマンド実行ができないことがあるため、「引き継ぎ文書を作る」機能が最も確実です。

## 使ってみる

![使ってみる](docs/img/ja/step4.svg)

普通の言葉で頼むだけです。

```
clara-muz-team でREADMEを読んで誤字を探して
ai-memory に「ボタンは青」とメモして
ai-memory で引き継ぎ文書を作って
```

Claudeアプリでは `/clara-muz:clara-muz-team`、`/clara-muz:ai-memory` のようにスラッシュでも呼び出せます。

- 最初に、AIが「ファイルを読んでよいですか？」「コマンドを実行してよいですか？」と聞くことがあります。内容を確認して許可してください。
- 相手のAIのコマンドが無ければ「インストールしてよいですか？」と聞かれます。**「はい」**と答えると、公式の方法でインストールします。その後、そのアプリにログインしているかだけ確認してください。

> 画像は**イメージ図**です。実際の画面とは少し異なる場合があります。

## 安全に使うために

- 相手のAIに任せる作業は**読み取り専用が基本**で、ファイルを変更するときだけ書き込みモードを使います。
- 作業中のフォルダの外には触れないよう指示します。(指示であり、強制的なブロックではありません。)
- 共有メモには**パスワード、キー、個人情報を書かないでください。**プレーンテキストのファイルです。
- メモの場所: Mac/Linux `~/.clara-muz/memory/`、Windows `C:\Users\<ユーザー名>\.clara-muz\memory\`

## よくある質問

- **お金はかかりますか？** ClaraMuzは無料です。ClaudeとChatGPTは、お使いのサブスクリプションのままです。
- **Node.jsやサーバーは必要ですか？** いいえ。
- **片方のAIだけでも使えますか？** はい。メモと引き継ぎは使え、作業はそのAI自身のサブワーカーで分担します。相手のAIを使わなかった場合は、AIがそう伝えます。
- **メモはどう受け渡されますか？** 片方が書いたメモファイルをもう片方が読みます。引き継ぎメモは1度受け取ると `claimed` に変わり、二重に受け取られません。[ai-memory](https://github.com/akitaonrails/ai-memory) のアイデアを軽く借りていますが、2つは独立したプロジェクトです。
- **メモを毎回自動で読ませたい。** 「ai-memory で init して」と頼むと、アプリの共通指示ファイルに1行のルールを追加します(確認のうえ)。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| コマンドが効かない | アプリを完全に終了して、もう一度起動してください |
| 「`codex` / `claude` が見つかりません」 | AIがインストールを提案したら「はい」と答えるか、アプリの公式インストール手順に従ってください |
| 「ログインが必要」と表示される | そのアプリ(ClaudeまたはChatGPT)にログインしてから、もう一度試してください |
| ChatGPTのPluginsタブに表示されない | マーケットプレイスの追加が完了したか(会社アカウントは管理者のインポートが完了したか)を確認し、アプリを再起動してください |
| Claudeでマーケットプレイスを追加できない | 管理者が外部マーケットプレイスをブロックしている可能性があります。管理者に確認してください |
